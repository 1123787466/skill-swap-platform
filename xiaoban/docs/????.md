## 六、质量门（Quality Gates）

每阶段交付前必须通过：

| 门 | 检查 | 通过标准 |
| --- | --- | --- |
| G1 编码 | 中文注释、英文变量名 | 100% |
| G2 浏览器 | 无 console 报错 | 0 error |
| G3 兼容 | Chrome + Edge + Safari 移动端 | 主流程通 |
| G4 安全 | 敏感词触发后必有引导 | 100% |
| G5 兜底 | 真实 AI 失败回落 Mock | 100% |
| G6 数据 | localStorage 刷新不丢 | 100% |
| G7 文档 | 每阶段对应文档同步 | 7/7 |
