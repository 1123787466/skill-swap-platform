PROJECT 01

技能互换平台

产品经理项目 · 双向发布的技能交换社区

01

双向发布 + 智能匹配 + 消息撮合

0→1 独立完成 · 已部署 GitHub Pages 公网上线
产品经理项目 匹配算法 Web 原型
🎯 项目背景 技能学习市场长期存在供需错配：C 端用户学习新技能面临"报班贵（数千元起）、自学难坚持（完课率不足 15%）、缺乏反馈"三大痛点；同时大量有一技之长的普通人缺少低门槛的分享与变现渠道。传统知识付费平台以单向内容交付为主，未解决"学完无处练、会教无人约"的闭环缺口。
💡 用户洞察 技能学习者真正的阻碍不是"找不到内容"，而是"缺少低成本、强约束、有反馈的学习伙伴"。每个学习者同时也是一个潜在的教学者——学吉他的可能擅长 Python，学摄影的可能懂英语。将"我想学的"与"我能教的"在同一用户身上双向撮合，用零金钱成本的身份互换替代付费报班，天然形成学习契约与社交约束，解决坚持难的问题。
🔐 登录注册

手机号 + 验证码登录，新用户自动注册，即开即用

📤 双向需求发布

分别发布"我能教的"（熟练度、标签、期望换到的技能）与"我想学的"（当前水平、目标），形成个人技能名片

🧭 发现与撮合

技能广场支持类型/分类/方式/关键词多维筛选，技能详情卡片展示对方"想换的技能"，提升双向转化

🧠 智能匹配引擎

加权算法：分类命中 50%、技能标签/关键词重合 30%、双向契合度 25%、交换方式兼容 5%，输出匹配评分与契合理由，双向契合者优先推荐

💬 消息与交换闭环

发起交换即生成结构化交换请求会话，支持附言沟通与模拟聊天，形成"发现-匹配-沟通-交换"完整链路

👤 个人中心

资料管理、我发布的技能、收到的/发出的交换请求三 Tab 管理，数据看板呈现匹配与请求概览
